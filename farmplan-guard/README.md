# FarmPlan Guard

A tiny, dependency-free Python library for validating task schedules generated by farm-planning tools.

## Why it exists

AI-assisted planning systems can produce schedules with missing fields, invalid priority labels, or more tasks assigned to a time slot than the available workforce can handle. FarmPlan Guard provides a small validation layer that can be reused by agentic applications before showing a plan to a user.

## Features

- Validate required schedule fields.
- Detect duplicate start times as a simple potential conflict.
- Detect start-time buckets with more tasks than available workers.
- Standard-library only; no network or API keys.

## Important limitation

The conflict detector groups tasks by exact start time. It does not infer task duration or detect overlapping intervals with different start times. Treat findings as basic checks, not a complete workforce scheduler.

## Run tests

Python 3.10+ recommended:

```powershell
py -m unittest discover -s tests -v
```

## Quick example

```python
from farmplan_guard import detect_conflicts, validate_schedule

tasks = [
    {"time": "09:00", "task": "Irrigate", "duration": "20 min", "priority": "High"},
    {"time": "09:00", "task": "Inspect field", "duration": "30 min", "priority": "Medium"},
]
print(validate_schedule(tasks))
print(detect_conflicts(tasks, workers=1))
```
